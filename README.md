# GratefulMoments-pages

[日本語版](README.ja.md)

## Overview

Static public landing, privacy, and support pages for GratefulMoments.

## Status

Public GitHub Pages repository.

## Features / Scope

- Keep the default branch stable and reviewable.
- Prefer small pull requests with clear test evidence.
- Keep product, release, and governance decisions documented in the repository.

## Quickstart

Open `index.html` locally, or use GitHub Pages after merging changes to `main`.

## Development

Use feature branches for changes and keep generated caches, local editor state, and secrets out of Git.

## Test / CI

Run the standard repository checks and verify pages render from GitHub Pages.

## Release / Deployment

Document release steps in this repository before treating a build or page as shipped. Public web repositories should confirm the deployment status after every merge to `main`.

## Security / Privacy

Do not commit credentials, personal data, local machine paths, generated databases, or App Store / deployment secrets. See [SECURITY.md](SECURITY.md).

## Governance

Repository operation follows [CONTRIBUTING.md](CONTRIBUTING.md), the pull request template, and staged `protect-main` rules where available. Private repositories document the same policy even when GitHub plan constraints prevent rulesets.

## Support

Open a GitHub issue for tracked work, or use the support contact documented by the product when available.
